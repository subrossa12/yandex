# Чеклист по требованиям Яндекс Игр

Сверено с официальной страницей «Требования к игре» (редакция от 18 августа
2026 года), а вызовы SDK — с документацией разделов «Подключение»,
«Загрузка игры и разметка геймплея», «Данные игрока», «Реклама»,
«Инап-покупки», «Лидерборды», «События», «Оценка игры» и «Серверное время».

Ниже — каждый пункт, который применим к этой игре, и где он закрыт.
Проверяется автоматически двумя инструментами:

- `sh tools/build.sh` — технические требования к архиву; при нарушении
  архив не собирается;
- `node tools/smoke.js` — поведение игры в реальном Chromium на семи
  размерах окна.

Обозначения: ✅ закрыто кодом · 📋 действие в Консоли/черновике · — не применимо.

## Удалённая конфигурация (флаги)

Требование здесь одно и жёсткое: **игра обязана полностью работать при
недоступной удалённой конфигурации.** Как это закрыто:

| Что | Как сделано |
|---|---|
| Локальные дефолты | Все 111 настраиваемых чисел зашиты в `data/balance.js` и работают без сети |
| Один запрос | `ysdk.getFlags()` вызывается ровно один раз на старте, никогда по ходу игры |
| Таймаут | Запрос гонится наперегонки с таймером (`remoteConfig.timeoutMs`, 3 с). Зависший промис не задерживает загрузку — проверяется тестом |
| Мусор на входе | Каждое значение парсится по типу и проходит санитарную проверку. Плохой флаг отбрасывается поштучно, остальные применяются |
| Единая точка чтения | `SE.Config.getFlag(key)`; остальной код не знает, откуда пришло значение |

Что можно крутить из Консоли, не пересобирая билд: цены и доходность всех
девяти точек, `costGrowth`, цены менеджеров, пороги ускорения, все апгрейды,
формула престижа целиком, кап офлайн-дохода, награды и кулдауны всех пяти
рекламных офферов, правила межстраничной рекламы, номер счётчика Метрики.

Прикинуть новый баланс до заливки флагов можно локально:

```sh
node tools/simulate.js 120 --flag prestige.factor=180
```

## Аналитика

Счётчик Метрики подключается номером в `data/balance.js` (`metrica.counterId`)
или флагом `metrica.counterId`. **Пока номер пуст — счётчик не грузится и
игра не делает ни одного внешнего запроса вообще.**

Цели, которые нужно завести в интерфейсе Метрики:

| Цель | Когда снимается |
|---|---|
| `first_manager_bought` | куплен первый менеджер — момент, когда игра начинает играть сама |
| `prestige_done` | выполнен престиж |
| `offline_income_claimed` | забран офлайн-доход |
| `wall_hit` | игрок больше минуты не может позволить себе вообще ничего |
| `rv_shown_<offer>` | запущен ролик: `speed`, `cash`, `discount`, `offline`, `prestige` |
| `rv_rewarded_<offer>` | ролик досмотрен и награда выдана |
| `iap_purchased_<id>` | покупка прошла |

Разрыв между `rv_shown_*` и `rv_rewarded_*` показывает, где оффер не
дожимается; `wall_hit` — где именно ломается воронка забега.

## Что осталось сделать руками

1. **Черновик:** ориентация — портретная; устройства — мобильные и десктоп
   (без Android TV); включить «Игра использует облачные сохранения»;
   возрастной тег 0+; email для связи.
2. **Консоль:** товары `noads`, `x2forever`, `offline8h`, `starterpack`
   (или поменять id в `data/shop.js`) и лидерборд с именем `total`.
   Пока их нет, магазин и таблица лидеров просто не показываются.
3. **Инапы:** после добавления товаров и публикации черновика написать на
   `games-partners@yandex-team.ru`, указав название и ID игры, и дождаться
   подтверждения — без этого покупки не заработают.
4. **Метрика:** создать счётчик, вписать его номер в `metrica.counterId`
   (или задать флагом) и завести перечисленные выше цели.
5. **Флаги:** завести в Консоли те ключи, которые собираетесь крутить.
   Заводить все 111 сразу не нужно — незаданные берутся из билда.
6. **Арт:** иконка, обложка, скриншоты — по разделам 5 и 8.
