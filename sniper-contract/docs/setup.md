# Что выставить руками

## Unity

**Версия и рендер:** Unity 6, шаблон 3D (URP).

**Player Settings → WebGL:**

| Настройка | Значение | Зачем |
|---|---|---|
| Compression Format | Brotli | вдвое меньше, чем gzip |
| Decompression Fallback | выкл | иначе Brotli теряет смысл |
| Managed Stripping Level | High | вес билда — главный риск |
| IL2CPP Code Generation | Faster (smaller) builds | то же |
| WebGL Template | YandexGames (из `Assets/WebGLTemplates`) | стандартный шаблон модерацию не проходит |
| Color Space | Gamma | линейный на WebGL дороже, а разница не окупается |
| Auto Graphics API | оставить WebGL 2 | |
| Run In Background | вкл | иначе игра встаёт при показе рекламы |
| Exceptions | Explicitly Thrown Exceptions Only | полные исключения весят заметно |

**Quality:** оставить один уровень качества, тени — Hard Only, дальность
теней порезать. Целевой вес распакованного билда — 30–40 МБ.

**Always Included Shaders:** добавить `Universal Render Pipeline/Lit` —
`GreyboxBuilder` ищет его через `Shader.Find`, и без этого в билде
материалы станут розовыми, хотя в редакторе всё выглядело нормально.

**Сцена:** одна пустая сцена, на ней один объект с компонентом
`Sniper.Core.Game`. Всё остальное собирается в рантайме.

## Плагин

Поставить PluginYG2, включить модули из `docs/plugin-api.md`, убедиться,
что символ `YG2` появился в Scripting Define Symbols. Пройти список
«Обязательное к проверке» из того же файла.

Десятый урок курса по плагину — оптимизация и настройка Unity под
Яндекс Игры. Это ровно наш главный технический риск, посмотреть до
первой сборки.

## Консоль разработчика

1. **Черновик:** ориентация — ландшафтная; устройства — мобильные и
   десктоп (Android TV не заявлять: там запрещены инапы); включить
   «Игра использует облачные сохранения» (п. 1.11); возрастной тег;
   email для связи.
2. **Лидерборды:** два, с техническими именами `total` (суммарный счёт)
   и `range` (лучшее попадание по дальности). Пока их нет, вызовы молча
   игнорируются.
3. **Товары** для инапов. Идентификаторы: `noads`, `rifle_<id>`,
   `module_<id>` — разбор при старте смотрит именно на эти префиксы.
4. **Инапы заработают только после письма** на
   `games-partners@yandex-team.ru` с названием и ID игры. Написать
   после добавления товаров и публикации черновика, дождаться
   подтверждения.
5. **Метрика:** создать счётчик, вписать номер в `metrica.counterId`
   (в `balance.json` или флагом), завести цели:
   `mission_started_<id>`, `mission_failed_<id>_<reason>`,
   `mission_3stars_<id>`, `rv_shown_<offer>`, `rv_rewarded_<offer>`,
   `iap_purchased_<id>`, `rifle_unlocked_<id>`.
6. **Флаги:** заводить только те ключи, которые собираетесь крутить.
   Незаданные берутся из билда.
7. **Sticky-баннер** включается здесь же, а не в коде.

## Ассеты

Только CC0, вести `CREDITS.txt`. Единый визуальный стиль важнее
детализации: low-poly со стилизованным освещением выглядит цельно и
весит мало, а «реалистично» из разнородных бесплатных ассетов выглядит
как свалка и весит втрое больше.
